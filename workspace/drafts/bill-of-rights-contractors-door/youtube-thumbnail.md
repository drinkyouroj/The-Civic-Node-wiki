## Per-tool quirks (pick the block matching your render tool)

**Freepik / Pikaso / Mystic:** Paste the prompt into the image-generation field. Attach the picked reference image via the "character reference" or "Pikaso character" feature. Set aspect to 16:9. The character-reference instruction at the top of the prompt is the standard Freepik phrasing.

**Nano Banana 2 / Gemini Imagen:** Upload the picked reference image first, then paste the prompt. Gemini handles "use the attached reference image as character reference" natively. (Fixed seed not configured — `~/.config/tcn/illustrated-justin-seed` not present.)

**Midjourney:** Append `--cref <reference-image-URL> --ar 16:9 --cw 100` to the end of the prompt. Trim the character-reference instruction at the top (becomes redundant with `--cref`). One ref per generation — the skill picks the single best ref per variant.

**Flux Kontext / image-to-image:** Set the picked reference image as the input image, denoise strength ~0.7. The character-reference instruction can be trimmed; keep the wardrobe/style directive as the prompt body.
