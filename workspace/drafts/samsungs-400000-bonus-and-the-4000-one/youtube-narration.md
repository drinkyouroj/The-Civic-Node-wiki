## Format note (read me first)

This deck uses a **beat-segmented motion format**, not the legacy static-slide format. The 11 `[SLIDE]` markers are *scenes* (each still maps to one template type for the slideshow skill). Inside each scene, the narration is broken into **beats** — one short spoken unit + the single visual element that lands on that beat + a `[stop]`.

**Division of labor:**
- **This script owns the beat boundaries and the stops** — where the reveal triggers, where you pause when recording. Perform straight down the beats; pause at every `[stop]`.
- **The slideshow skill owns the animation *style*** — *how* each element arrives (fade, slam, count-up, wipe), easing, transitions. The `element:` note names *what* lands, never *how* it moves.

Target screen-static window: ~2-3 seconds per beat. 109 beats over ~7:05 ≈ one visual change every ~3.9s on average, tighter on the stamp/number beats.
