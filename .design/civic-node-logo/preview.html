11 — Usage Rules
Do
  • Use mark + wordmark horizontal lockup in Substack header
  • Use mark-favicon.svg for all favicon contexts (16–48px)
  • Use slate-600 (#3A6A8F) for all light-background contexts
  • Use monochrome (#E4E4EC) for print or single-color use
  • Maintain minimum 16px clearspace around the lockup
  • Scale proportionally — always from a corner handle
Don't
  • Don't rotate, skew, or distort the mark
  • Don't apply gradients, shadows, or glow effects
  • Don't use the full mark (with crossbar) below 48px
  • Don't place the mark on backgrounds lighter than #1A1A24 in dark mode
  • Don't use rounded linecaps — the mark requires square caps
  • Don't use on busy photographic backgrounds without an overlay
